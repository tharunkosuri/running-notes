DNS propagation failures

on-premise -> cloud
servers IP addresses are going to be changed
TTL present -> 1 day
TTL -> 1min. gets the record as fresh with TTL 1min

more TTL -> DNS resolution latency is very less
less TTL -> DNS resolution latency is more

TTL -> 1 day
atleast before 2 days TTL update to 1min
DNS propagation will be very fast when IP addresses are updated.

change back TTL to 1 day

rare customers -> 10 days back, TTL is expired. he will get latest IP address
best customer -> every hour he is using. TTL is still active. he always get old IP address, which is not available
