redirections
============
> symbol is for redirection
>> -> append

1 -> success
2 -> error

ls -l > output.log == ls -l 1> output.log  --> This will store only success output

ls -ldfjdsUHFRDF 2> output.log --> This will store only failure output

ls -l &> output.log  --> this will store both success and failure output

&> --> This will also override the previous output
&>> --> This will append the previous output

ls -l | tee -a output.log --> This will also show in screen along with storing it in log file
