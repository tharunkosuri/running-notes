IMP:***************************** Mongodb Instllation **********************

dnf install will try to get the repos from /etc/yum.repos.d/ 
mongodb is not there in this repo. So to install mongodb first we need to add mongodb in this repo

1) vim /etc/yum.repos.d/mongo.repo
2) [mongodb-org-7.0]
name=MongoDB Repository
baseurl=https://repo.mongodb.org/yum/redhat/9/mongodb-org/7.0/x86_64/
enabled=1
gpgcheck=0

3) dnf install mongodb-org -y
4) systemctl enable mongod
5) systemctl start mongod
6) netstat -lntp (127.0.0.1 == localhost)
NOTE: ***
By default MongoDB listens only on localhost (127.0.0.1), so only applications on this same server can reach it. Catalogue and User run on other servers, so MongoDB must listen on all addresses.

Update the listen address from 127.0.0.1 to 0.0.0.0 in /etc/mongod.conf:
***
7) after making config changes restart the server --> systemctl restart mongod
8) netstat -lntp (0.0.0.0:27107) ---> now it will accept the connections from other servers like catalogue and cart
*******************************END MongoDB Instllation ***********************************

IMP : ******************** Redis Instllation *************************

1)dnf module disable redis -y
2)dnf module enable redis:7 -y
3)dnf install redis -y
4)netstat -lntp (127.0.0.1 == localhost)
NOTE : ******
By default Redis listens only on localhost (127.0.0.1). User and Cart run on other servers, so Redis must listen on all addresses.

5)edit the config file --> vim /etc/redis/redis.conf
Update bind 127.0.0.1 -::1 to bind 0.0.0.0 -::1
Update protected-mode yes to protected-mode no
*******
6)systemctl enable redis
7)systemctl start redis

************End Redis Instllation **********************

NOTE : Rabit MQ is an Asyncrynous communication (Producer,Consumer,Topic,brokers) --> fire the message and forgot
EX: User --> System1(Producer) ---> Broker --> System2(Consumer)

RabbitMQ is not there in this repo. So to install RabbitMQ first we need to add RabbitMQ in this repo

1) vim /etc/yum.repos.d/rabbitmq.repo
2) dnf install erlang rabbitmq-server -y
3) systemctl enable rabbitmq-server
4) systemctl start rabbitmq-server

NOTE : *******
RabbitMQ comes with a default user guest/guest, but guest can only connect from the same server. Create a user for the application:

rabbitmqctl add_user roboshop roboshop123
rabbitmqctl set_permissions -p / roboshop ".*" ".*" ".*"
